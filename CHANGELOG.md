# Changelog

## 1.0.0 — First public release

- First public release of the plugin for QGIS 4 / Qt6.
- Multi-format editor (Python, Markdown, QSS, XML/UI, TXT, config files), dynamic PyQGIS language service, AST diagnostics with quick fixes, integrated Designer, Markdown preview, QSS/XML/TXT formatting, snippets, code wizard, Python console, project search, UI translation management.
- Sub-plugin extension system with multilingual translations: per-extension `translations/<language>.json` catalogs and the `core/ext_i18n.py::ExtensionBase` base class.
- Bundled extensions: `local_history` (snapshots with rotation and folder exclusions), `todo_panel`, `i18n_checker` (translated warning when no project is open), `session_manager`, `bookmarks`.
- Removed the file comparison (diff) feature from the Tools menu, the tab context menu and the extensions; removed the related translation keys.
- Extension translation fix: modules loaded by the ExtensionManager are now registered in sys.modules, so extensions can locate their own `translations/<language>.json` catalogs (previously they always fell back to the inline messages).
- Extensions expose `retranslate()`: action texts and icons update when the IDE language changes; a warning is written to the log if the catalog for the chosen language is missing.
- Dedicated icons for all extensions (history, todo, i18n, session, bookmark).
- TODO panel renamed to "Menu di controllo"; checkable action "Mostra menu di controllo"; translated Refresh/Clear buttons; the tree empties automatically when the project is closed; Refresh scans the project without blocking when no tabs are open.
- "Guida alle estensioni" menu entry cleaned up (no more "(IT/EN)" suffix).

## 2.2.3

- Compatibility and startup fixes for QGIS 4 / Qt6.
- `QAction` and `QActionGroup` are now imported from the correct Qt6 module (`QtGui`).
- The automatic dependency check now also verifies all plugin UI/runtime modules and the fundamental Qt/QGIS symbols.
- The code generated by **New project** now uses the correct Qt6 import for `QAction`.
- Removed the IDE's internal theme management: the plugin no longer overrides palettes, backgrounds or editor colors configured in QGIS.
- The editor now uses the colors assigned in the QGIS options.

## Markdown fixes and editor position

- Markdown formatting keeps the selected text at its original position and leaves it selected after applying markers.
- Formatting without a selection inserts the markers at the cursor position and leaves the cursor between prefix and suffix.
- Fixed operations for bold, italic, underline, strikethrough, inline code, superscript, subscript, links, images and code blocks.
- Headings, lists, checklists and blockquotes now preserve cursor, selection and scroll position.
- Markdown toolbar buttons no longer take focus, preventing selection loss during formatting.
- The Markdown renderer continues to use the font configured in QGIS.
